How to use this manual, roles, and signing in

How each process is laid out

Every process has the same parts, so you can find your way quickly:

The people and what they can do

RoleDoesCannot do
AdministratorEverything: admissions, students, academics, staff, settings, users, backups.Nothing is closed to an admin.
TeacherAttendance and marks for their own classes and subjects, homework, library, requesting inventory. Can read most other screens.Fees, admissions, staff records, settings.

The menu only shows what your role may open. If a menu entry is missing, it is not meant for your role. Your administrator can also create custom roles, for example a Librarian who only sees the library.

Signing in

  1. Open the school's address in a browser (during setup this is http://localhost:5173).
  2. Type your email and password and press the sign-in button.
  3. If you were given a temporary password (new student accounts and new teacher logins always are), the system asks you to change it first. Nothing else works until you do. Choose at least 8 characters, different from the temporary one.
  4. To leave, use Logout at the bottom of the left menu. Do this on shared computers.
Watch outToo many wrong passwords locks sign-in for that email for 15 minutes. Do not keep trying; ask the administrator to reset the password.
Before going live (administrator)Change the starting admin password (admin123) and the secret key in the server settings. Anyone who has seen the example file knows them.
Part 2

Finding your way

The screen

  • Left menu: one group per area (Admissions, Students, Academics, Fees & Finance and so on). Click a group to open its pages.
  • Top bar: a search box, a theme button (light, dark or follow your device), and your name with Logout.
  • Page header: the page title and the main action on the right, for example + New enquiry.
  • Summary tiles under the header count what is on the page. They are a quick health check: if a tile looks wrong, something needs attention.
  • Tabs (All, New, Follow-up, Converted and so on) show a slice of the list, each with a count.
  • Search and filters narrow the table. Type a name, a phone number or an ID. Every word you type must match.

Handy shortcuts

Ctrl + KJump to any page you may open, find a student by name, switch theme, or sign out.
Type-ahead boxesWherever a form needs one student or one staff member you get a search box, not a long list. Type part of the name, admission number or phone and pick from the results.
EscCloses a popup. If you typed something, the system asks before throwing it away.

Popups and forms

Most "add" and "edit" forms open as a popup over the list. Fields marked * are required. A red message at the top of the popup tells you what to fix. Clicking the dim background does not close a popup, so you cannot lose work by accident.

What happens when you delete

Soft deleteNothing important disappears at once. A deleted record is hidden and remembered, with who deleted it and when. Enquiries even have a Deleted tab where you can Restore them. Only an already-deleted enquiry can be removed permanently.
  • A student with a certificate request cannot be deleted. Mark the student inactive instead.
  • Staff with payslips, reviews or documents cannot be deleted. Mark them inactive.
  • A fee that has any payment cannot be deleted. Use a discount or fine to change what is owed.
  • An issued certificate can never be deleted; it is part of the register.

Everything is recorded

Every create, change and delete is written to the Audit log with the person and time. Saved attendance that is corrected keeps the old value, the new value and the reason. Work as if your name is on every change, because it is.

Part 3 · Administrator

Setting up the school

Do these once, in this order. Later processes read what earlier ones create: you cannot enrol a student into a class that does not exist, or bill a fee that has no structure.

School profile→Academic year→Master data→Classes→Subjects & map→Staff→Fee structure→Timetable→Users
WhoAdministrator
WhereSettings, Academics, Staff & HR, Fees & Finance, User Management
TimeAbout 4 to 6 weeks for a whole school

3.1 School profile

  1. Open Settings → School Profile.
  2. Edit the name, code, board, contact details, principal and motto. Upload the logo as a PNG or JPEG up to 1 MB.
  3. Set the current academic year here or under Academic Years. Save.
Check it workedThe school name and logo now appear on the sign-in page, in the header, and on every printout (receipts, report cards, ID cards, certificates).

3.2 Academic year and campus

  1. Academics → Academic Years: add the year (for example 2026-2027) and make it current.
  2. Settings → Branches: the first campus is the main one. Add more only if the school has more.

3.3 Master data (the dropdown lists)

  1. Open Settings → Master Data.
  2. Review religion, category, nationality, mother tongue, state, relation, occupation, qualification and marital status. Rename, hide or reorder as the school needs.
  3. Open the three document lists (Application documents, Student documents, Staff documents). Tick Required on each document the school insists on, for example birth certificate and address proof.
Watch outAn application cannot be submitted until every required application document is uploaded. Decide these carefully before admissions open.

3.4 Classes and sections

  1. Academics → Classes & Sections → add a class with its name (for example Grade 5) and section (A).
  2. Add the room and, when staff exist, the class teacher.

Name plus section must be unique. "Grade 5 A" cannot be created twice.

3.5 Subjects and the subject map

  1. Academics → Subjects: add each subject once.
  2. Academics → Subject Map (or Class Map): for each class add its subjects.
    • Core subjects are taken by everyone; elective subjects belong to a group (for example "Second language") and each student takes one.
    • Choose theory, practical or both. For both, set the practical share (30% of 100 marks means 70 theory plus 30 practical).
    • Set periods a week and the teacher.
Check it workedThe Class map page shows one class at a glance: teacher, subjects, fees, activities, transport and hostel. The Setup guide in Help ticks each step from real data and shows what a class still lacks.

3.6 Staff and teacher logins

  1. Staff & HR → Departments and Designations: add the lists first.
  2. Staff Directory → register each staff member (see Part 10).
  3. User Management → Users: create a login for each teacher. The login email must be exactly the same as the email on the staff profile. That is how the system knows which classes and subjects belong to the teacher.
  4. On Classes, pick the staff member as class teacher. The teacher then gets a My Class page.

3.7 Fee structure

  1. Fees & Finance → Fee Types: tuition, transport, lab and so on.
  2. Fee Structure: for each class add its fee items with amount and due date.
  3. Optional: Fee Groups are reusable bundles (for example "Uniform pack") that a family can choose at admission.
  4. Settings → Payments: receipt number prefix, which payment methods are accepted, whether part payments are allowed.

3.8 Timetable

  1. Academics → Class Timetable: choose a class and place subjects into days and periods with teacher and room.

A room cannot serve two classes at the same time, and one-off room bookings cannot clash with lessons. Completion is measured against the periods the subject map asks for.

3.9 Loading many records from a spreadsheet

  1. Settings → Data Import / Export.
  2. Pick what you are loading. The order that works is: classes, subjects, departments, designations, staff, curriculum, fee types, fee structure, books, students.
  3. Download the template, fill it in (the example row shows the format), and upload it.
  4. First the system checks every row and lists every problem in plain words. Fix the file and upload again. Only a file with no problems is imported, all in one go.
Safe to repeatRows already in the system are reported as "already there" and skipped, so you can re-upload a corrected file without creating duplicates. Logins, parent accounts and the timetable are not imported on purpose: they involve passwords and decisions.
Part 4 · Admissions officer (administrator)

Admissions: enquiry to enrolment

Enquiry→Application→Under review→Assessment→Offer→Enrol→Student

One admissions record follows the family the whole way. Nothing is typed twice, and everything collected moves to the student when you enrol.

WhoAdministrator
WhereAdmissions group in the menu
Before you startClasses, academic year, required documents, fee structure

4.1 Record an enquiry

  1. Admissions → Admission Enquiries → + New enquiry.
  2. Fill the four sections: student, parent, enquiry details (grade applying for, and where the enquiry came from: website, walk-in, phone, referral, social media or other) and follow-up plan.
  3. Save. The enquiry gets a number like ENQ-2026-0012.

Enquiries from the school website's /apply form arrive here automatically, marked as online.

4.2 Follow up

  1. Open the row's menu and choose to plan a follow-up or visit. Pick the date, the way you will contact them and a note.
  2. When the date arrives, the enquiry moves to the Follow-up tab and the "Needs follow-up" tile counts it.
  3. After you call, record the outcome. A campus visit date shows in the "Visits scheduled" tile.

4.3 Start the application

  1. On the enquiry row click Apply, or open Admissions → Admission → New admission.
  2. Step 1, Student: first and last name, date of birth, grade applying for, academic year, personal details. Click Continue to guardians. The draft is saved and gets its own address, so you can leave and come back.
  3. Step 2, Guardians: primary guardian, relationship, phone number, address, and contact and local guardian details. If a brother or sister already studies here, click + Add a sibling and fill the relation, admission number or employee code, name and class. You can add up to 10. Click Continue to schooling.
  4. Step 3, Schooling: previous school, qualifications, then what the family wants: an elective from each group, activities, a bus route and stop (always both), a hostel bed, a fee group. Upload the required documents in the checklist: each slot has Upload, Replace and Remove, and "needed" ones are marked until uploaded. Click Continue to review.
  5. Step 4, Review: read the summary, tick the consent box and click Submit application. The button stays disabled until consent is ticked.
Check it workedThe application appears under Admission with the stage Under review, and the enquiry shows as Applied.
Watch out
  • Submit fails if a required detail, a required document or the consent is missing. The message names what is missing.
  • You cannot move an enquiry to "applied" any other way. The application form is where the required details are collected.
  • Documents must be PDF, JPG, PNG or WebP, up to 5 MB each, at most 10 per application. The system looks inside the file; renaming a file does not fool it.
  • An elective must belong to the grade chosen, one per group. A route needs a stop.

4.4 Test, interview and offer

  1. Entrance Tests: schedule a test date for a submitted application; after the date, enter the marks (maximum marks must be above zero).
  2. Interview Schedule: set date, time and panel (all three are required); after the interview, record the result.
  3. Decide: Approve (needs the class applied for), Waitlist, or Reject (the applicant can be reopened later as an enquiry). The Waiting List entry shows waitlisted applicants.
  4. An approved applicant has an offer with a confirm-by date (14 days by default). Admission Offers lists them; after the date the offer shows as expired.
Watch outA test or interview can only be scheduled for a submitted application. Marks and results cannot be entered for a date that is still in the future.

4.5 Enrol

  1. On the approved applicant's row click Enroll. The button changes to "Sure? Click again to enroll". Click it a second time.
  2. A green message appears: Enrolled as ADM-2026-xxxx; N fee item(s) billed, together with the student's login username and starting password.
  3. Write the password down now. It is shown only once. Hand it to the family; the student must change it at first sign-in.
  4. If the family asked for a hostel bed, the message says what is left to do: the hostel desk must choose a room (Part 13).

What enrolment did for you, in one step

Student recordCreated in the class applied for, with a generated admission number and every detail from the enquiry and application, including siblings.
LoginA student login with a starting password.
FeesEvery fee item in that class's structure billed, once. Fee group items chosen by the family are billed alongside.
Documents and photoThe application's documents become the student's documents (same names); the photo becomes the student's photo.
ChoicesElective subjects, activity registrations and the bus assignment are created.
Check it workedOpen Students → Enrolled Students, find the child, open the details popup: subjects, bus, activities, documents and the sibling details are all there.
Undoing a mistakeIf you enrolled the wrong person, delete the student. The applicant goes back to holding an offer, so nothing points at a student that no longer exists. A student with certificate requests cannot be deleted; mark them inactive.
Part 5 · Administrator

Students: records, logins, documents

WhoAdministrator (teachers can read)
WhereStudents group
Before you startClasses and fee structure

5.1 Register a student directly (without an application)

  1. Students → Enrolled Students → Register new student.
  2. Required: first name, last name and the admission number (leave it blank and one is generated).
  3. Choose the class. Tick the option to bill the class fee structure if you want fees raised now.
  4. Fill what you know: parents, contact, address, previous school, siblings, remarks. Save.
Watch outIf a student with the same name and date of birth exists, the system asks you to confirm before creating a duplicate. Look at the existing record first.

5.2 Photo and documents

  1. Open the student's details popup.
  2. Upload the photo (one per student; a new one replaces the old).
  3. In the document checklist upload each required document. A badge shows when required documents are missing.

Photos are JPEG, PNG or WebP up to 1 MB. Documents are PDF or images up to 5 MB. Files are stored in the database, so backups contain them.

5.3 Create logins

ForWhereNotes
StudentStudents → Student AccountsOne login per student. Stops working when the student is made inactive. The password is temporary.
ParentParent Portal → Parent Accounts, or Create parent login on the student's profileCan be filled from the father, mother or guardian details already on the student and links the child on save. One parent can be linked to several children.

5.4 Health, behaviour and clinic

Student Health Records holds blood group, allergies, regular medication and the emergency contact. Clinic Visits and Student Behavior record events against a student. Teachers and admins can use these.

5.5 Changing a student's class or electives

  1. Edit the student and choose the new class, or open the details popup and change an elective directly.
  2. The system removes electives that do not belong to the new class.

5.6 When a student leaves

  1. Issue a Transfer Certificate (Part 15).
  2. Set the student to inactive. Their login stops, they no longer appear in attendance sheets or ID card runs, and their history stays.
Do not delete a student who has historyDeleting hides the record. If the student has certificate requests, the system refuses. Inactive is almost always the right answer.
Part 6 · Academic coordinator, teachers

Academics: subjects, electives and timetable

6.1 Electives: how a student chooses

  1. The class's elective subjects sit in groups such as "Second language".
  2. A family picks one per group on the application, or the office sets it later in the student's details popup.
  3. Exams then expect marks only for the student's own subjects, and ranks are worked out of those.

6.2 Teaching tools

PageUse it to
Syllabus & Lesson PlansPlan topics per class and subject and track their status.
Homework & AssignmentsSet homework with a due date; the tracker shows who submitted.
Online ClassesAdd a live class with its joining link; students and parents see the last week and what is coming.
Study MaterialsShare links and materials by class and subject.
Academic Calendar, List of HolidaysPublish terms, events and holidays; they show in the portal.

6.3 Substitutions

  1. Timetable → Substitution Management.
  2. The page lists the periods of teachers on approved leave.
  3. Pick cover. The system only offers teachers who are free: no lesson, no other cover, not on leave.

6.4 Timetable reports

Timetable Reports shows teacher workload, periods per class, room use and periods that still have no teacher. Check it before the term starts.

Part 7 · Teachers

Daily teaching: attendance, leave and alerts

WhoTeachers (and admin)
WhereAttendance group, My Class
WhenEvery school day, early

7.1 Mark attendance

  1. Open Dashboard → My Class, or Attendance → Mark Attendance. A class teacher's page opens on their own class.
  2. Check the date (today) and the class.
  3. For each student choose present, absent or late. For a late student add the arrival time (like 08:15) and, if useful, a short note (up to 120 characters).
  4. Save. The button tells you when there are unsaved changes.
Check it workedThe dashboard tile "Present today" updates, and the parent of an absent child can see it in their portal. If automatic alerts are on, the guardian is notified.
Watch outYou cannot mark a future date, or a student who is not in the class. A teacher can only open their own classes.

7.2 Correct a saved mark

  1. Change the mark the same way and save, or use Attendance Corrections.
  2. Give a reason. The system records the old value, the new value, the reason and who changed it.

7.3 Student leave

  1. A parent applies in their portal (Apply for Leave) with dates and a reason. A student can also apply from their own portal.
  2. You see it under Attendance → Student Leave and on My Class as "waiting for a decision".
  3. Approve, or Reject with a reason (a reason is required).
  4. Student Leave Record shows the history; Leave Balances shows days used.
RulesLeave cannot be requested for dates already over. Overlapping pending or approved leave is refused. Leave that has already started cannot be cancelled.

7.4 Monthly, period and biometric attendance

  • Monthly Attendance: a sheet for a class and month; every change must fall in that month.
  • Period Attendance: attendance per period for a class and day.
  • Biometric Attendance: card or fingerprint devices send marks directly; the page shows what arrived.

7.5 Parent absence alerts

  1. Attendance → Parent Absence Alerts.
  2. With Automatic alerts on, the system checks every few minutes and notifies guardians of students marked absent, once per absence.
  3. You can also send a text for one absent student from this page.
Is it really sending?Until the school's email and SMS credentials are set up, messages are only recorded in the history as "recorded only" and are not delivered. Ask the administrator to confirm under Settings → Integrations.

7.6 Reports

Reports → attendance for any date range and class. Students below the minimum (75% by default) are flagged. Use Export to download what is on screen.

Part 8 · Exam cell, teachers

Exams: marks, results and report cards

Grade setup→Create exam→Enter marks→Results & ranks→Report card
WhoAdmin creates; teachers enter marks
WhereExaminations group
Before you startSubject map, students in the class

8.1 Grade setup (once)

  1. Examinations → Grade Setup.
  2. Add grades with a name (up to 10 characters) and the lowest percentage for each. The lowest grade must start at 0%, and no two grades can start at the same percentage.
  3. Set the pass mark (0 to 100, 40% by default). Save; the button reads Saved until you change something.

8.2 Create an exam

  1. Exams, Marks & Results → create: class, name, maximum marks, dates.
  2. The tiles show all, upcoming, ongoing and completed exams from the dates.
  3. Optional: Exam Groups combine several exams with weights (1 to 1000) into one result. An exam can only join a group of its own class.

8.3 Enter marks

  1. On the exam row click Marks.
  2. Type each student's mark in the box. For a subject taught as theory plus practical there are two boxes, each checked against its own maximum, with the total beside them.
  3. Click Save marks. You see Marks saved. If you try to leave with unsaved marks, the system warns you.
Watch out
  • A mark cannot be higher than the maximum.
  • Only students of the exam's class, and only subjects that class studies, are accepted.
  • A teacher can enter marks only for the subjects assigned to them in the subject map. An admin can enter any.

8.4 Results, ranks and the merit list

  1. Click Results on the exam. The tiles show students, passed, class average and top score; tabs show Pass, Fail and Incomplete.
  2. Each student has a total, percentage, grade and rank. A student is ranked out of the subjects they take, so electives are fair.
  3. Merit List shows the top students; it prints without the controls.

8.5 Print a report card

  1. On the results row open the student's report card.
  2. Check the school name, logo, student photo, marks table, total, percentage, grade, rank, result and attendance.
  3. Click Print. The sheet prints cleanly with lines for class teacher, parent and principal signatures.

8.6 Revaluation

  1. A parent can raise a request in the portal, or a teacher logs one under Revaluation Requests.
  2. Only one request can be open per subject. The admin accepts (enters the revised mark and a note) or rejects (a reason is required).

Holistic Progress Card records non-academic areas (skills and habits) alongside marks.

Part 9 · Accountant

Fees and payments

Fee structure→Billing→Payment→Receipt→Reports
WhoAccountant, administrator
WhereFees & Finance group
Before you startFee structure per class

9.1 How fees reach a student

  • At enrolment, every item in the class's fee structure is billed automatically.
  • Bill a class: Fees & Payments → Bill a class bills every student of the class for the structure items. A student is never billed twice for the same item.
  • Add fee: a single fee for one student (a student, a title and an amount above zero).
  • Hostel, transport and library fines are billed through this same page, so everything one family owes is in one place.

The page shows tiles for billed, collected, outstanding and overdue, tabs by status, search and a class filter.

StatusMeaning
UnpaidNothing paid yet and not yet past the due date.
Partly paidSome money received, balance remains.
OverdueNot fully paid and the due date has passed.
PaidPaid amount equals the amount.

Status is worked out by the system from the amounts and the date. You never type it.

9.2 Take a payment

  1. Fees & Payments: find the fee (search by student name, admission number or phone).
  2. Click Pay. In the popup enter the amount and choose the method (cash, card, bank transfer and so on; only the methods switched on in Settings appear).
  3. Save. The receipt opens with its own number.
  4. Click Print and give the receipt to the payer.
Check it workedThe fee's balance drops and its status changes to Partly paid or Paid. Payment History & Receipts lists the payment and you can reprint the receipt later.
Watch outThe system will not take more than the balance. If part payments are switched off in Settings, only the full balance is accepted.

9.3 Discount, fine and refund

  1. On the fee click Discount or Fine. A reason is required (for example "Sibling discount", "Scholarship").
  2. A discount cannot bring the amount below what has already been paid.
  3. To refund, open the payment in Payment History and choose refund. The refund is recorded against that payment.
  4. Late fines: the late fines action bills fines for overdue fees in one go.
Never try to "fix" a fee by deleting itA fee with any payment history, even fully refunded, cannot be deleted, moved to another student or re-priced. Use a discount or a fine. If you billed the wrong student and nothing was paid, delete the fee and bill the right student.

9.4 Fee reminders

  1. Fee Reminders lists guardians with overdue fees.
  2. Send the reminder. The same guardian is not reminded again for 24 hours (the cool-down is in Settings).

9.5 Other income, expenses and reports

  • Other Income and Expenses: record non-fee money in and out, with a category.
  • Financial Reports: tabs for attendance, Income & expenses (with collection by method and expenses by category) and Fee defaulters. Each has tiles, search and Export.
End-of-day routineOpen Payment History, filter to today, compare the total with the cash drawer and the bank slips, and Export for the records.
Part 10 · HR (administrator), accountant

Staff and payroll

10.1 Register a staff member

  1. Staff & HR → Staff Directory → register new staff member.
  2. Fill employment (staff number is generated if blank, designation, department, type, joining date), personal and identity details, contact and address, qualification and experience, emergency contact and bank details.
  3. Upload the photo and the required staff documents (Staff Documents): contracts, certificates, ID proofs. PDF or image, up to 5 MB.
Who sees whatIdentity, address and emergency data are visible to administrators only. Bank details are visible to administrators and accountants. Other roles see names, designation, department, contact and joining date.
Watch outStaff with payslips, reviews or documents cannot be deleted. Mark them inactive instead.

10.2 Staff attendance and leave

  • Staff Attendance and Monthly Staff Attendance record and review daily presence.
  • Staff Leave: a staff member applies; the admin approves or rejects (reason needed). Staff Leave Balance shows allowances and days used. Leave types and yearly allowances are in Settings.
  • Approved leave feeds Substitutions automatically.

10.3 Payroll, every month

Salary terms→Generate payslips→Admin approves→Paid
  1. Accountant: Payroll → Salary terms tab: set each staff member's basic salary, allowances and deductions. Basic salary is required.
  2. Accountant: pick the month and generate payslips. Deductions cannot be more than the gross salary.
  3. Check the tiles: staff on payroll, net payroll, paid, and waiting for approval.
  4. Administrator only: open a payslip and click Approve & mark paid. The approver's name is recorded on the payslip.
Watch outThe accountant prepares, the administrator approves. This split is deliberate and enforced. A paid payslip cannot be deleted.

10.4 Recruitment

  1. Recruitment: create an opening with job title and number of vacancies.
  2. Add applicants and move them: applied, shortlisted, interviewed, offered, hired.
  3. Only an offered applicant can be hired. Hiring creates the staff profile and closes the opening when all vacancies are filled.

10.5 Performance reviews

  1. Performance Reviews: choose the staff member and give each of the four ratings from 1 to 5 (every rating is required). The average is worked out for you.
  2. When final, finalise the review. A finalised review cannot be changed or deleted.
Part 11 · Librarian, teachers

Library

Categories→Books→Cards→Issue→Return→Fines

11.1 Books and categories

  1. Library → Book Categories: add categories first. A category with books cannot be deleted.
  2. Books & Loans → add a book with title, author, category and number of copies. You can also load books from a spreadsheet (Part 3.9).

11.2 Library cards

  1. Library Members → issue a card: card number, valid-until date, books allowed at a time (1 to 50) and status (active or suspended).
  2. A student with a card is held to its limit. A student without a card can still borrow unless the school requires a card in Settings.

11.3 Issue and return

  1. Books & Loans → Issue a book: search the student, choose the book and the loan period (14 days by default, never more than 90).
  2. When it comes back, click Return on the loan.
  3. If it is late, a fine (per day, set in Settings) is billed to the student as a normal fee, once.
The system will refuse when
  • the student is inactive, or already has this book on loan, or is at the card limit;
  • the card is suspended or expired;
  • no copy is free, or the free copies are being held for students who reserved first.

11.4 Reservations

  1. Book Reservations → reserve a book only when no copy is free.
  2. When a copy is returned it is held for the first person in the queue, so no one can jump ahead.

11.5 Fines from earlier returns and reports

On Books & Loans use Bill fines from earlier returns to bill late returns made before fine billing was switched on; running it again does not bill twice. Library Reports shows the most borrowed books and titles per category.

Part 12 · Transport manager

Transport

Vehicles→Drivers→Routes & stops→Assign riders→Fees→Attendance

12.1 Set up

  1. Transport → Vehicles: registration number and seats.
  2. Drivers & Attendants: add the staff who run the buses.
  3. Routes: name, vehicle and monthly fee. Stops: stops in order; a stop belongs to one route.

12.2 Assign a student to a bus

  1. Student Route Assignment → assign: choose the student, the route and stop (the stop must be on that route), the trips used (both, pickup only or drop only) and who is authorised to collect the child.
  2. Editing the row moves the rider.
RulesA vehicle never carries more than its seats. Only active students can use transport. A route or stop with riders cannot be deleted.

19.2 Backups

  1. Automatic: the system writes a backup file about once a day to the server's backups folder and keeps the newest 14.
  2. Copy that folder somewhere else (another disk, a cloud drive). A backup on the same disk as the database does not survive that disk failing.
  3. Manual: Settings → Backup & Restore → download. The file holds every table, including uploaded photos and documents, and password hashes. Keep it private.
  4. Restore replaces all data in one step: you must type RESTORE, the file must be a School ERP backup that contains user accounts, and any error rolls everything back. Practise this on a test copy before you ever need it.

20.2 Hands-on exercises

Exercise A: one family, whole process (session 10)

  1. Record an enquiry for a child; plan a follow-up.
  2. Start the application; add a sibling; upload the required documents; submit.
  3. Schedule a test and an interview; record the results; approve; make the offer.
  4. Enrol; note the student's login password; check fees were billed.
  5. Pay the fee in two parts; print both receipts.
  6. Create a parent login; sign in as the parent and look at fees.
  7. Mark attendance for the class; enter marks for an exam; print the report card.
  8. Raise a certificate request as the parent; issue it at the office.
  9. Promote the class and check the ID card.

Exercise B: break it on purpose (all sessions)

  • Try to submit an application without a required document. Read the message.
  • Try to pay more than the balance. Try to delete a fee that has a payment.
  • Enter a mark higher than the maximum.
  • Try to issue a book that is already on loan to the same student.
  • Try to enrol an applicant who has not been approved.

The aim is for staff to meet each refusal in training, so it does not frighten them in real use.

Exercise C: recover (administrators)

  • Delete an enquiry, find it in the Deleted tab, restore it.
  • Correct a saved attendance mark and find the correction record.
  • Download a manual backup. On a test copy, restore it.

  • Backup folder is copied off the server on a schedule; one restore has been practised on a test copy.
  • One real class rehearsed end to end; what the pilot showed has been fixed.
